## Les trois blocs professionnels

**Bloc 1 — Préparer les opérations de transport** (U2, écrit ponctuel)

| Code | Compétence | Compétences détaillées |
|---|---|---|
| C1.1 | Prendre en compte la demande du client / donneur d'ordre | collecter les informations nécessaires (en français ou en langue étrangère) ; sélectionner les données utiles ; identifier les caractéristiques de la marchandise, de son emballage et de son conditionnement ; détecter les contraintes et impératifs, y compris l'incoterm |
| C1.2 | Choisir les modalités de l'opération de transport | sélectionner le ou les modes / techniques de transport ; choisir les moyens humains et matériels ; prendre en compte les prestations associées ; sélectionner les opérateurs / sous-traitants |
| C1.3 | Optimiser l'offre de transport | déterminer ou sélectionner un itinéraire ; déterminer les temps de conduite, de repos et de travail ; élaborer un plan de chargement |
| C1.4 | Élaborer la cotation de l'offre de transport | appliquer les grilles tarifaires ; valoriser les prestations annexes ; établir coût de revient et prix de vente ; formaliser et communiquer l'offre |

**Bloc 2 — Mettre en œuvre et suivre des opérations de transport** (U31, CCF)

| Code | Compétence | Compétences détaillées |
|---|---|---|
| C2.1 | Constituer le dossier transport | collecter et vérifier les données / documents ; renseigner ou saisir les données ; actualiser et contrôler le dossier |
| C2.2 | Exécuter la demande du client / donneur d'ordre | réserver le ou les moyens de transport ; planifier l'opération ; procédures de sûreté et de sécurité ; saisir les données des documents de transport ; mettre à jour les données du déroulement ; transmettre informations, documents et instructions par le moyen adapté |
| C2.3 | Suivre l'opération de transport et communiquer avec les interlocuteurs | assurer la traçabilité (moyen propre ou sous-traité) ; prendre en compte le statut douanier ; traiter les incidents ; suivre les autres opérations en cours ; rendre compte de l'avancée aux interlocuteurs |

**Bloc 3 — Contribuer à l'amélioration de l'activité de transport** (U32, CCF)

| Code | Compétence | Compétences détaillées |
|---|---|---|
| C3.1 | Contrôler les engagements contractuels avec le client / donneur d'ordre | vérifier la concordance avec les engagements ; identifier puis traiter anomalies, réclamations, litiges ; vérifier les éléments nécessaires à la facturation ; clôturer le dossier ; relation suivie ; satisfaction du client |
| C3.2 | Participer à la gestion des moyens matériels et humains | contrôler temps de conduite et de repos ; transmettre les infractions ; formations, certifications, habilitations du personnel roulant ; données du parc ; maintenance et contrôles ; **suivre les supports de charge, tenir à jour leurs mouvements** |
| C3.3 | Actualiser les tableaux de bord | sélectionner, saisir et vérifier les données ; transmettre les indicateurs |
| C3.4 | Contribuer à l'amélioration de la performance | variation des indicateurs ; application des procédures ; documents de synthèse ; proposer des actions ; rendre compte |

## Savoirs associés (titres relevés)

Bloc 1 : organisation de la profession et d'une entreprise de transport, intervenants de la chaîne
logistique, modes et techniques de transport, caractéristiques de l'envoi, géographie des transports,
termes du commerce international. Bloc 2 : gestion électronique des documents, dossier et documents de
transport, éléments déclaratifs et régimes douaniers, sûreté, outils de traçabilité. Bloc 3 : facture
de prestation, anomalies et litiges, relation client, chronotachygraphe, parc de véhicules, tableaux de
bord, qualité, RSE, risques professionnels.

## ⚠ Collision de codes

Les codes **C1.1 à C3.4 existent aussi en Logistique 2025 et au CAP 2026, avec d'autres intitulés**
(C1.1 OTM = « prendre en compte la demande » ; C1.1 Logistique = « supply chain »). Dans Prepalog,
les codes OTM se notent **`OTM-C1.1`** etc.

## Points de contact avec la Logistique (utiles pour la 2de)

- **Supports de charge** : OTM C3.2 ↔ Logistique C2.5.
- **Litiges et anomalies** : OTM C3.1 / C2.3 ↔ Logistique C1.4.2.
- **Plan de chargement, itinéraire** : OTM C1.3 ↔ Logistique C2.4 (tournée).
- **Confier l'expédition** : la Logistique C2.6 est la même opération **vue du chargeur** ; l'OTM la
  voit **du transporteur / commissionnaire**.
- **Traçabilité** : OTM C2.3 ↔ Logistique C3.2.
